# Changelog

## 0.1.0

First preview release.

- Custom editor for `.vectorcraft` files, rendered by `vectorcraft-cli` (PNG or SVG).
- Zoom, pan, fit, actual size, background switcher, artboard picker.
- Live reload when the file changes on disk; works on git versions of a file.
- Downloads `vectorcraft-cli` on request from the official releases, checks the SHA-256 checksum.
  Also finds `vectorcraft-cli` on `PATH` or in a VectorCraft install.
- Open in VectorCraft, view the JSON source.
- English and French.
